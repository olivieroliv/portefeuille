Analyse par Claude

Sur votre abonnement Claude, sans coût d’API. Claude travaille seul, sur GitHub (5 à 20 minutes) : il cherche, ligne par ligne, les résultats, la valorisation, l’avis des analystes et l’actualité (AFP, Reuters, sites d’analyse financière) — pas d’analyse technique — et le rapport s’affiche ici. Vos chiffres (sans nom ni numéro de compte) passent par votre dépôt GitHub privé. Ou copier la demande pour l’app Claude.
Ou, rangée dans cette page, l’analyse par la clé API de Vigie (payante : le coût estimé s’affiche avant). Rien n’est envoyé sans votre appui. Ce n’est pas un conseil en investissement.

Relevé de compte

Le relevé DEGIRO (fichier CSV) donne vos versements et retraits — c'est lui qui permet le XIRR, le rendement annuel de votre argent — ainsi que les dividendes, impôts, frais et opérations de change. Importez-le une fois depuis l'ouverture du compte ; ensuite, après chaque versement ou retrait, importez un relevé récent : les mouvements déjà connus ne sont pas comptés deux fois.
